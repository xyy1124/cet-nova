# CET Nova

免费、开源、离线优先的四六级智能备考平台。

**在线版：<https://xyy1124.github.io/cet-nova/>**
**当前状态：V0.1 已部署，包含 2024 年 12 月两套真实六级真题**

## 现在就能跑

```bash
npm install
npm run dev      # http://localhost:5174
```

离线版：`npm run build && npm run preview`，Service Worker 只在 build 后注册。

## 三条铁律

1. **真题与 AI 物理隔离**——关掉 AI，软件仍是完整可用的刷题工具。
2. **答案挂选项语义，不挂字母**——多套卷选项重排，字母复用必错。
3. **内容不随代码分发**——代码 MIT，真题/音频走外部来源 + 用户本地导入。

## 已实现

真题解析流水线（PDF → 结构化 → 答案关联 → 校验）、130 分钟考试模式、
阅读三种题型桌面左右分栏、听力播放器、逐题解析、错题本、CET6 词库划词查义、
IndexedDB 持久化、数据导出导入、PWA 离线（关掉服务器仍可用）、浅色/深色主题。
